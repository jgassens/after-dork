AFTER DORK for Windows
Chemistry screen savers, arriving a mere thirty years late.

GETTING STARTED

1. Unzip this folder somewhere, e.g. your Downloads folder.
2. Double-click AfterDork.exe.
   Windows may warn that it "protected your PC": click "More info",
   then "Run anyway". (The app isn't code-signed. It is, however,
   biblically accurate.)
3. Pick a module, fiddle the sliders, and press:
     Demo              to try it full screen right now, or
     Set Screen Saver  to make it your actual screen saver.

"Set Screen Saver" copies After Dork into
%LOCALAPPDATA%\Programs\AfterDork, so you can delete this folder
afterwards. To change modules or options later, run AfterDork.exe
from there (or from this folder, if you kept it).

The Monitor box sets how long before the screen saver starts and when
the display goes to sleep. If the display sleeps first you will never
see the flasks, and that would be a shame.

Requirements: Windows 10 or 11 (64-bit). Nothing else to install.

THE .SCR FILES

Each <Module>.scr is a classic Windows screen saver. Right-click one
and choose "Install" to pick it in Windows' own Screen Saver Settings,
or "Test" to run it.

UNINSTALLING

Pick another screen saver in Windows Settings, then delete
%LOCALAPPDATA%\Programs\AfterDork and %APPDATA%\AfterDork.
