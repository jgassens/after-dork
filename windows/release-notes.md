## 🪟 After Dork 1.2.1 for **Windows**

**This is the Windows version** for 64-bit Windows 10 and 11. It has all eight chemistry screen savers and the retro control panel.

> 🍎 **On a Mac?** These downloads won't run on your Mac. Get **[After Dork for Mac](https://github.com/jgassens/after-dork/releases/latest)** instead.

## Installing it

1. Download the zip above, right-click it, and choose **Extract All**.
2. Open the folder and double-click **AfterDork.exe**.
   - If Windows says it *protected your PC*, click **More info** and then **Run anyway**. The app isn't code-signed. It is, however, biblically accurate.
3. Pick a module and fiddle the sliders. Press **Demo** to try it full screen, or **Set Screen Saver** to make it your screen saver.

**Set Screen Saver** copies After Dork into `%LOCALAPPDATA%\Programs\AfterDork`, so you can delete the downloaded folder afterwards. Each `<Module>.scr` file also works the classic way: right-click it and choose **Install**.

## What's in it

The same eight modules as the Mac app, with the same options:
- Flying Flasks
- Schlenk Pipes
- Lattice Maze
- Mystify Origami
- Stoddart Reef
- Orbital Box
- SMILES Rain
- Castaway Chemist

The Monitor box sets how long before the screen saver starts and when the display sleeps. On Windows, display sleep doesn't need an admin password. **Updates…** checks this page for newer Windows builds.

Requires a 64-bit PC running Windows 10 or 11.
